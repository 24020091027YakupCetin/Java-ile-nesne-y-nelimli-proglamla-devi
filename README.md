
# Java ile Nesne Yönelimli Programlama - 2. Hafta Ödevi

Bu depoda, Nesne Yönelimli Programlama (OOP) dersi 2. hafta ödevi kapsamında hazırlanan Java uygulamaları ve ekran görüntüleri yer almaktadır.

## İçerik
- **Sınıf (Class) ve Nesne (Object) Yapısı:** Sınıf tanımlama ve nesne oluşturma örnekleri.
- **Kapsülleme (Encapsulation):** `private` değişkenler, `getter` ve `setter` metotlarının kullanımı.
- **Yapıcı Metotlar (Constructor):** Parametreli ve parametresiz yapıcı metot örnekleri.
